#MediGuide – Health Triage & Hospital Recommendation System

MediGuide is a web application that helps users record symptoms and vital signs, view an initial health risk assessment, and find hospital information.

##Features

- User registration and login
- Health assessment based on symptoms and vital signs
- Risk level and recommended doctor type
- Assessment history
- Hospital information and recommendations
- Responsive web interface

##Technology Stack

- Frontend: React, JavaScript, HTML, CSS
- Backend: Java, Spring Boot, REST APIs
- Database: PostgreSQL
- Deployment: Render
- Database Hosting: Neon PostgreSQL

##Live Demo

##https://mediguide-health-triage-system.onrender.com

##Repository Structure

- "frontend/" – React application
- Backend source files – Spring Boot application
- Database configuration – Environment-based settings

##Getting Started

1. Clone this repository.
2. Configure the required database environment variables.
3. Start the Spring Boot backend.
4. Install frontend dependencies using "npm install" inside the frontend directory.
5. Start the frontend using "npm run dev".
